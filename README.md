# BrandFusion

BrandFusion is a zero-backend procedural prompt generator for **brand × product** concept design.

It does not use an LLM to compose prompts. The browser-side engine combines:

- brand design DNA
- product anatomy and functional constraints
- material-class compatibility
- controlled fusion modes
- deterministic seeded variants
- scene / camera / lighting presets
- realism and manufacturability constraints
- a responsive fusion / merge animation

## Files

- `index.html` — UI / HUD
- `styles.css` — minimalist responsive interface and mixing animation
- `app.js` — brand/product datasets, compatibility engine and prompt compiler

## Usage

Choose or randomize a brand and product, select the fusion intensity and visual scene, then copy the generated image prompt.

The project is static and can be hosted directly with GitHub Pages.
